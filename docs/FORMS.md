# 구글 폼 구성안

폼은 **4개**입니다. 투표는 따로 만들지 않고 **4차시 폼 안에 들어 있습니다.**

| 폼 | 언제 | 앱 설정 이름 | 주소 |
|---|---|---|---|
| 1차시 | 서약 + 기획 제출 | `FORM1_URL` | https://forms.gle/R2GAM63r7s1a7BkF8 |
| 2차시 | 제작 기록 제출 | `FORM2_URL` | https://forms.gle/99kn5JcNCUVdMpYJA |
| 3차시 | 수정 기록 + **게임 파일** 제출 | `FORM3_URL` | https://forms.gle/iBcs9eRWFVcs1QPH8 |
| 4차시 | **투표** + 소감 제출 | `FORM4_URL` | https://forms.gle/zWHepC66HQ9us9b37 |

주소는 `site/index.html` 맨 위 `CONFIG`에 이미 들어 있습니다. 폼을 새로 만들면 그 값을 바꾸고 푸시하세요.
학생용 앱의 [제출용 요약 복사]는 맨 위에 `[차시] 학번 이름`과 `서약서: 날짜 서명 완료`를 넣어 줍니다.

## 공통 설정

- 로그인 필수, 이메일 주소 수집(확인된 사용자)
- 폼은 **내 드라이브**에 만드세요. 공유 드라이브에 두면 파일 업로드 문항을 쓸 수 없습니다.
- **응답 1회 제한은 4차시 폼(투표)만** 켭니다. 나머지는 학생이 고쳐서 다시 제출할 수 있게 꺼 두세요. (마지막 제출이 쓰입니다.)
- 학교 관리자가 데이터 유출 방지(DLP)를 켜 두었다면 파일 업로드가 막힐 수 있습니다. 학생 계정으로 시험하세요.

## 폼 1 · 1차시

| 문항 | 유형 | 필수 |
|---|---|---|
| 학번 (5자리, 예: 20315) | 짧은 답변 + 정규식 `^[1-3](0[1-9]\|1[0-6])(0[1-9]\|[1-3][0-9]\|40)$` | 예 |
| 이름 | 짧은 답변 | 예 |
| 요약 붙여넣기 (앱의 [제출용 요약 복사]) | 장문 | 예 |

서약 확인: 요약 맨 위에 `서약서: … 서명 완료`가 있으면 서명한 것입니다. `ingest.py --form1 응답.csv`로 서명 안 한 학생 명단도 뽑을 수 있습니다.

## 폼 2 · 2차시

학번, 이름, 요약 붙여넣기(장문). 폼 1과 같은 문항입니다.

## 폼 3 · 3차시 (게임 파일)

| 문항 | 유형 | 필수 |
|---|---|---|
| 학번, 이름, 요약 붙여넣기 | 폼 1과 같음 | 예 |
| 게임 파일 (.html) | **파일 업로드**, 파일 1개, 용량 상한은 **1MB 이상** 중 가장 작은 값 | 예 |

- 업로드된 파일은 선생님 드라이브의 폼 이름 폴더에 쌓입니다. 폴더째 내려받아(zip) `ingest.py`에 넣으세요.
- 파일 이름은 폼이 바꿀 수 있어서, `ingest.py`는 파일 이름이 아니라 **파일 첫 줄의 제출 표식**(학번·이름·게임 이름·설명)을 읽습니다.
- 여러 번 올리면 마지막 파일만 사용합니다.

## 폼 4 · 4차시 (투표 + 소감)

| 문항 | 유형 | 필수 |
|---|---|---|
| 학번, 이름 | 폼 1과 같음 | 예 |
| 우리 반 | 드롭다운 (1반 … 16반) | 예 |
| 과학적으로 가장 정확한 작품 (번호) | 짧은 답변, 숫자 1~99 | 예 |
| 가장 재미있는 작품 (번호) | 짧은 답변, 숫자 1~99 | 예 |
| 가장 창의적인 작품 (번호) | 짧은 답변, 숫자 1~99 | 예 |
| 가장 실용적인 작품 (번호) | 짧은 답변, 숫자 1~99 | 예 |
| 소감 요약 붙여넣기 (앱의 [제출용 요약 복사]) | 장문 | 예 |

- 투표는 **반별로만** 합니다. 학생은 4차시 탭 갤러리에서 본 우리 반 작품 번호를 입력합니다.
- 자기 작품에 투표하는 것은 폼으로 막을 수 없습니다. 번호는 `private/mapping.csv`로만 작성자와 연결되므로 필요하면 선생님이 응답의 학번과 대조하세요.

### 투표 집계 (응답 시트)

응답 시트에서 열 위치를 확인한 뒤 새 탭에 아래 수식을 쓰면 득표 순위가 나옵니다. 열 순서는 폼 문항 순서를 따르므로 실제 시트에서 확인해 고치세요. (수식은 직접 시험하지 못했습니다.)
예) `A 타임스탬프, B 이메일, C 학번, D 이름, E 우리 반, F 정확, G 재미, H 창의, I 실용, J 소감`

```
=QUERY('폼 응답 1'!E:I, "select G, count(G) where E = '3반' and G is not null group by G order by count(G) desc label G '작품 번호', count(G) '득표'", 1)
```

- 부문마다 `G`(재미)를 `F`·`H`·`I`로 바꾸세요. 이메일이 들어 있으니 이 시트는 **공개하지 마세요.**

## 자동 생성 스크립트 (선택)

`tools/make_forms.gs`를 script.google.com에 붙여넣고 `makeAllForms`를 실행하면 같은 구성의 폼 4개가 만들어집니다. 이미 폼을 만들었다면 필요 없습니다. 파일 업로드 문항(폼 3)은 직접 추가해야 하고, 실제 계정에서는 시험하지 못했습니다.

## 수업 전 시험 체크리스트 (학생 계정으로)

- [ ] 폼 4개가 학생 계정(학교 도메인)으로 열린다
- [ ] 폼 3에서 `.html` 파일이 올라가고 1MB 이상 용량 상한을 고를 수 있다
- [ ] 앱 링크와 갤러리가 열린다
- [ ] 앱의 서명 팝업에서 터치스크린·터치패드로 서명이 그려진다
- [ ] 요약 복사 → 폼 붙여넣기가 된다
- [ ] 4차시 폼 투표가 되고, 한 번만 제출된다
