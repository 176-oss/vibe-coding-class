# 구글 폼 구성안

폼은 4개입니다. 모두 **학교 계정 로그인 필수**로 설정하고, 폼 이름에 차시를 넣어 학생이 헷갈리지 않게 하세요.
학생용 앱의 [제출용 요약 복사]는 맨 위에 `[차시] 학번 이름`과 `서약서: 날짜 서명 완료`를 넣어 줍니다.

## 공통 설정

- 설정 → 응답: **응답 1회로 제한**(로그인 필요), 이메일 주소 수집(확인된 사용자)
- 폼은 **내 드라이브**에 만드세요. 공유 드라이브에 두면 파일 업로드 문항을 쓸 수 없습니다.
- 학교 관리자가 데이터 유출 방지(DLP)를 켜 두었다면 파일 업로드가 막힐 수 있습니다. 수업 전에 학생 계정으로 시험하세요.

## 폼 1 · 1차시 (서약 + 기획)

| 문항 | 유형 | 필수 |
|---|---|---|
| 학번 (5자리, 예: 20315) | 짧은 답변 (정규식: `^[1-3](0[1-9]\|1[0-6])(0[1-9]\|[1-3][0-9]\|40)$`) | 예 |
| 이름 | 짧은 답변 | 예 |
| 앱의 [제출용 요약 복사]를 눌러 아래에 붙여넣으세요 | 장문 | 예 |

서약 확인: 요약 맨 위의 `서약서: … 서명 완료`가 있으면 서명한 것입니다. 시트에서 해당 문구가 없는 행을 필터하세요. (`ingest.py --form1`로도 확인할 수 있습니다.)

## 폼 2 · 2~3차시 (제작 + 게임 파일)

| 문항 | 유형 | 필수 |
|---|---|---|
| 학번, 이름 | 폼 1과 같음 | 예 |
| 제작 요약 붙여넣기 | 장문 | 예 |
| 게임 파일 (.html) | **파일 업로드**, 1개, 파일 크기 상한 **10MB 이하 중 가장 작은 값 이상** | 예 |

- 파일 형식은 `.html`이 허용되는지 확인했습니다(교사 확인). 선택지에 맞는 형식이 없으면 "기타" 형식을 확인하세요.
- 상한은 폼이 제공하는 선택지에서 1MB 이상으로 고르세요. 앱이 1MB 초과 파일을 내보내지 못하게 막고 있습니다.
- 업로드된 파일은 선생님 드라이브의 폼 이름 폴더에 쌓입니다. 폴더째 내려받아(zip) `ingest.py`에 넣으세요.
- 게임 파일이 없거나 여러 번 올리면 마지막 파일만 사용합니다. 파일 이름은 폼이 바꿀 수 있으므로 `ingest.py`는 파일 이름이 아니라 파일 첫 줄의 제출 표식을 읽습니다.

## 폼 3 · 4차시 (성찰)

| 문항 | 유형 | 필수 |
|---|---|---|
| 학번, 이름 | 폼 1과 같음 | 예 |
| 성찰 요약 붙여넣기 | 장문 | 예 |

## 폼 4 · 투표 (반별)

`tools/make_vote_form.gs`로 자동 생성하거나 직접 만듭니다.

| 문항 | 유형 | 필수 |
|---|---|---|
| 우리 반 | 드롭다운 (1반 … 16반) | 예 |
| 과학적으로 가장 정확한 작품 (작품 번호) | 짧은 답변, 숫자 1~99 | 예 |
| 가장 재미있는 작품 (작품 번호) | 짧은 답변, 숫자 1~99 | 예 |
| 가장 창의적인 작품 (작품 번호) | 짧은 답변, 숫자 1~99 | 예 |
| 가장 실용적인 작품 (작품 번호) | 짧은 답변, 숫자 1~99 | 예 |

- 투표는 **반별로만** 합니다. 학생은 자기 반 갤러리의 번호를 입력합니다.
- 자기 작품에 투표하는 것은 폼으로 막을 수 없습니다. 번호는 갤러리와 `private/mapping.csv`로만 작성자와 연결되므로, 필요하면 선생님이 응답의 이메일과 대조해 확인하세요.

### 투표 집계 (응답 시트)

응답 시트의 열이 `A 타임스탬프, B 이메일, C 우리 반, D 정확, E 재미, F 창의, G 실용`일 때, 새 시트 탭에서 반과 부문을 바꿔 가며 아래 수식을 쓰면 득표 순위가 나옵니다. (수식은 시트에서 직접 시험해 보세요. 응답 시트의 열 순서와 이름이 다르면 수정해야 합니다.)

```
=QUERY('폼 응답 1'!C:G, "select E, count(E) where C = '3반' and E is not null group by E order by count(E) desc label E '작품 번호', count(E) '득표'", 1)
```

- 부문마다 `E`(재미)를 `D`·`F`·`G`로 바꾸세요.
- 이 시트는 **공개하지 마세요.** 이메일이 들어 있습니다.
- 앱의 실시간 순위 화면은 이번 범위에서 보류했습니다. 필요해지면 득표수만 담은 요약 탭을 "웹에 게시"해서 읽는 방식으로 이어 갈 수 있지만, 게시된 CSV를 다른 사이트에서 읽을 수 있는지는 아직 시험하지 않았습니다.

## 수업 전 시험 체크리스트 (학생 계정으로)

- [ ] 폼 1~4가 학생 계정(학교 도메인)으로 열린다
- [ ] 폼 2에서 `.html` 파일이 올라가고, 1MB 이상 용량 상한을 고를 수 있다
- [ ] 앱 링크와 갤러리 링크가 열린다
- [ ] 앱의 서명 팝업에서 터치스크린·터치패드로 서명이 그려진다
- [ ] 앱의 요약 복사 → 폼 붙여넣기가 된다
